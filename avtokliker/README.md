# Автокликер заявок

Для круглосуточного запуска на сервере: [команды установки и авторизация](deploy/INSTALL.md).

Основной режим — браузер: обновляет страницу приложения каждые 60 секунд,
читает DOM внутри iframe и нажимает видимые доступные кнопки и ссылки действия
в колонке «Предложения партнёров», независимо от текста, включая кнопки с иконкой.
Колонка определяется по заголовку (`browser.columnTitle`), а не по координатам.
Обычный текст «Нет свободных мест» не считается кнопкой. При медленной загрузке цикл занимает дольше
60 секунд; параллельные проверки не запускаются. Скрытые и отключённые кнопки
пропускаются. Фильтры keywords и seen.json относятся только к старому API-режиму.
В браузерном режиме принимаются все доступные заявки на открытой странице списка;
пагинация автоматически не обходится.

## Запуск в Windows

Нужны Python 3.10+ и Microsoft Edge. Из папки `avtokliker`:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src\avtokliker.py
```

В открывшемся браузере войдите в Битрикс24, откройте приложение и вкладку
«Заявки», затем нажмите Enter в консоли. Остановка — Ctrl+C или закрытие окна.
Профиль сохраняется в `browser-profile`, поэтому вход обычно нужен только один раз.
Не запускайте два экземпляра с одним профилем. Компьютер должен оставаться включённым.
При истечении сессии остановите программу и войдите заново.

В `config.json`: `pollIntervalSec` — интервал, `dryRun: true` — только поиск без
нажатий, `browser.channel: "chrome"` — использовать установленный Chrome.
Сейчас включён автоприём (`dryRun: false`). Отдельные диалоги подтверждения
автоматически не подтверждаются. Лог фиксирует нажатие, а не подтверждённое
сервером принятие заявки. Если приложение изменит разметку или заголовок колонки,
понадобится обновить настройки/селекторы.

Реализация использует [Playwright](https://playwright.dev/python/docs/frames).
Старый экспериментальный режим cURL доступен с `mode: "api"`; его endpoint
списка ещё не установлен, подробности в `docs/recon.md`.
