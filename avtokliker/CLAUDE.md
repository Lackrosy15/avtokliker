# Avtokliker — автоприём заявок партнёрского приложения Битрикс24

## Контекст

Портал: `crmby.bitrix24.by`, приложение `/marketplace/app/60/` — партнёрские заявки (лиды от Битрикс24).
Когда приходит заявка, партнёр вручную жмёт «Принять заявку» → создаётся сделка в CRM.
Заявки разбирают другие партнёры — важна скорость.

## Цель

1. Понять, куда идёт запрос при клике на «Принять заявку» (сниффинг через DevTools).
2. Автоматически брать подходящие заявки: поллинг списка + фильтр по ключевым словам + тот же запрос, что делает кнопка.

## Структура

- `config.json` — настройки (ключевые слова, интервал опроса, режим dry-run) — появится после разведки
- `src/` — код автокликера
- `docs/recon.md` — что выяснили про API приложения (endpoint, метод, payload, cookies)

## Принципы

- Сначала **dry-run** режим: скрипт только сообщает «нашёл подходящую заявку», не принимает.
- После ручной проверки — включаем автоприём.
- Все найденные endpoint'ы и payload'ы фиксируем в `docs/recon.md`.
